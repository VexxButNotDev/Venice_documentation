**Venice** is a moderation and server-management Discord bot built with Python and [discord.py](http://discord.py), using a modular cog architecture. It's designed to give staff teams a full toolkit for running a Discord community: onboarding new members, moderating chat, managing tickets, tracking staff activity, and integrating with the ERLC API (for servers running the roleplay platform).

<Tip>
  Ready to make this your own? Start by editing this page. Update your `docs.json` file to customize your site. Then fill out the [Quickstart](/quickstart) page.
</Tip>

<Card title="Commands" icon="rocket" href="/quickstart">
  Venice supports both classic prefix commands (`v!`) and slash commands (`/`) running in parallel for most features. Setup is centralized through a single guided wizard (`/setup`), so server admins don't need to touch config files directly.
</Card>
